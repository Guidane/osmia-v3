How values work

A value is text with {Field} placeholders, or a formula when it starts with =. In both, {Field} is the record the automation runs for, {old.Field} its value before the change, {this.Field} the record a step is changing, {item.Field} the linked record of a "for each" step and {found.Field} the record the last "find or create" found. A path follows links: {Part.Average cost}. To link a new record to this one, set its link field to =RECORD_ID().
