🌳 Trees and spaces

Any table can be a tree: each record has a parent in the same table. Records of every other table link to a tree's nodes as freely as to any record, so one task can be in a project, be done by a team and concern a location. A tree of spaces gives each of its records a page, with what links to it; everyone's home space is the record of a space table whose home field is them. Set this up in each table's settings.
